Lidarr Custom List of popular artists across major genres.

Raw URL for Lidarr:

https://raw.githubusercontent.com/T2112/lidarr-soulseek/main/lists/lidarr-custom-list.json

In Lidarr: Settings → Import Lists → + → Custom List → paste that URL.
Recommended: monitor Latest Album, turn off search-on-add until you like the batch.
Lidarr skips artists already in your library.
