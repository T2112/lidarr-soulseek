# Lidarr genre starter lists

Raw Custom List URL:

https://raw.githubusercontent.com/T2112/lidarr-soulseek/main/lists/lidarr-custom-list.json

Lidarr → Settings → Import Lists → + → Custom List → paste that URL.
Recommended: monitor Latest Album. Lidarr skips artists already in your library.
