## Safer add settings

Lidarr → Settings → Import Lists → + → Custom List → paste the URL above.

Recommended:
- Monitor: **Latest Album** (or First Album)
- Monitor new items: **New** or **None**
- Start search for missing albums: **off** until you have tagged the artist
- Add a tag such as `genre-starter` so you can delete the import if needed

Lidarr skips artists already in your library.
